# HomeKit 智能开关 (Smart Switch)

基于 HomeSpan 库开发的 HomeKit 智能开关设备，支持物理按钮控制和HomeKit远程控制。

## 功能特性

### 核心功能
- **智能开关控制**: 通过HomeKit App远程控制开关状态
- **物理按钮**: 支持本地物理按钮控制
- **状态同步**: 物理操作与HomeKit状态实时同步
- **LED指示**: 显示设备连接和运行状态
- **出厂重置**: 长按物理按钮恢复出厂设置

### HomeKit服务
- **Switch**: 开关服务
- **On**: 开关状态特性 (开启/关闭)
- **Name**: 设备名称特性
- **AccessoryInformation**: 设备信息服务

## 硬件要求

### 必需组件
- ESP32 开发板 × 1
- 继电器模块 × 1 (或其他开关设备)
- 按钮开关 × 1
- LED指示灯 × 1
- 连接线若干

### 引脚连接
```
ESP32 引脚    连接设备        说明
GPIO4        继电器/开关     开关控制输出 (低电平触发)
GPIO0        物理按钮        短按开关/长按重置 (内置上拉)
GPIO32       LED指示灯       HomeKit状态显示 (低电平点亮)
VCC          电源正极        3.3V/5V
GND          电源负极        公共地线
```

### 接线图
```
ESP32                    外部设备
┌─────────────┐         ┌──────────┐
│ GPIO4       ├─────────┤ 继电器IN │
│ GPIO0       ├─────────┤ 按钮     │
│ GPIO32      ├─────────┤ LED+     │
│ GND         ├─────────┤ 公共地   │
│ VCC         ├─────────┤ 电源+    │
└─────────────┘         └──────────┘
```

## 使用说明

### 设备配对
1. 编译并上传代码到ESP32
2. 设备启动后自动创建WiFi接入点
3. 使用iPhone/iPad打开"家庭"App
4. 点击"+"添加配件
5. 扫描QR码或输入配对码: `46637726`
6. 按照提示完成配对

### 操作方式
- **短按**: 切换开关状态 (开启/关闭)
- **长按**: 恢复出厂设置 (5秒)
- **HomeKit控制**: 通过家庭App或Siri语音控制

### 控制方法
- **家庭App**: 点击开关图标控制
- **Siri语音**: "嘿Siri，打开/关闭智能开关"
- **自动化**: 基于时间、位置、传感器的自动控制
- **快捷指令**: 创建自定义快捷指令

## 故障排除

### 常见问题
1. **开关无响应**
   - 检查继电器连接是否正确
   - 确认GPIO引脚设置无误
   - 检查电源供应是否充足

2. **HomeKit控制失效**
   - 检查WiFi网络连接
   - 确认设备在家庭App中状态正常
   - 尝试重启设备

3. **物理按钮不工作**
   - 检查按钮接线
   - 确认GPIO0引脚连接
   - 查看串口调试信息

4. **继电器不动作**
   - 检查继电器电源供应
   - 确认控制信号电平
   - 测试继电器是否损坏

### 调试方法
- 使用串口监视器观察设备日志
- 检查HomeKit连接状态
- 测试物理按钮响应
- 验证继电器控制信号
