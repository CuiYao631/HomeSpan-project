# HomeKit 门铃 (Doorbell)

基于 HomeSpan 库开发的 HomeKit 门铃设备，支持物理按钮触发门铃事件，适合智能家居场景。

## 功能特性

- **门铃事件**: 按下物理按钮后，HomeKit家庭App会收到门铃通知
- **设备名称**: 可在App中自定义显示
- **LED状态指示**: 显示HomeKit连接状态（可选）
- **主机名自定义**: 路由器中显示为“MyDoorbell”

## 硬件要求

- ESP32开发板 × 1
- 按钮开关 × 1（门铃按钮，接GPIO0）
- LED指示灯 × 1（可选，接GPIO32）

## 引脚连接

| ESP32引脚 | 连接设备   | 说明           |
|-----------|------------|----------------|
| GPIO0     | 门铃按钮   | 短按触发门铃   |
| GPIO32    | LED指示灯  | 状态显示（可选）|
| VCC       | 电源正极   | 3.3V/5V        |
| GND       | 电源负极   | 公共地线       |

## 软件配置

- HomeSpan库
- EasyButton库
- Arduino IDE

## 使用说明

1. 编译并上传代码到ESP32
2. 设备启动后自动创建WiFi接入点
3. 使用iPhone/iPad打开“家庭”App
4. 点击“+”添加配件，扫描二维码或输入配对码：`46637726`
5. 按下门铃按钮，App会收到门铃事件通知

## 场景应用

- 家庭门铃
- 智能通知
- 门口访客提醒
